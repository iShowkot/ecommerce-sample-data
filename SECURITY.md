# Security policy

This project ships data files and a few Python scripts, so security problems are unlikely. They're still possible, for example a URL in a CSV that points somewhere unsafe, or a script that handles input badly.

Please report security problems privately, not in a public issue. Use **[Report a vulnerability](https://github.com/iShowkot/ecommerce-sample-data/security/advisories/new)** on the repository's Security tab, and include the file and line or the steps to reproduce the problem.

Fixes go into the next release. Since the files are data, there are no supported older versions to patch: use the latest release.
